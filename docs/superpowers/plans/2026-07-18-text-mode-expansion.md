# The Marquee — Text-Mode Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 14 new text-based quiz modes (Multiple Choice Classic, True or False, Six
Degrees, Odd One Out, Cast Connect, Fact or Fiction, Behind the Scenes, Name the Show
from the Intro, Which Season?, Episode Title Match, Character Arc, Spot the Guest Star,
Adaptation Match, Same Actor Different Screen) to The Marquee, grouped into categories
in a restructured lobby, plus a Budget metric for the existing Higher or Lower mode.

**Architecture:** Every new mode reuses the existing generic `kind:'choice'` question
renderer (prompt + shuffled options) — no new interaction code. The lobby's flat mode
grid becomes a two-level nav: category tiles → per-category mode grid (same card
markup, reused). Marquee Mix needs no changes — `buildQueue('mix')` already pools
every key in `BANKS` automatically.

**Tech Stack:** Single self-contained `index.html` using a proprietary "DC" (design
component) template runtime: an HTML template with mustache-style `{{ binding }}`
placeholders, `<sc-if>`/`<sc-for>` control-flow custom elements, and a JS logic class
(`class Component extends DCLogic`) whose `renderVals()` method computes every
template binding each render. The entire page (template + logic) is stored, once, as
a JSON string inside `<script type="__bundler/template">` — this is why raw
`grep`/`Edit` against `index.html` shows escaped `\n`/`\"` sequences instead of real
newlines and quotes. **Never hand-edit that escaped blob directly.** Task 1 builds
tooling that unpacks it to a normal, real-newlines-and-quotes HTML file, lets you edit
it like any other file, and repacks it losslessly.

## Global Constraints

- No new question `kind` — every new mode must resolve to `kind:'choice'` via the
  `norm(id, it)` method's generic branch (the `tags` map fallback), matching the
  existing `emoji`/`quote`/`fact` modes' pattern.
- JS string literals in `template.html` use single quotes; escape embedded
  apostrophes as `\'` (e.g. `'Spielberg\'s lawyer'`) — match the existing style
  visible throughout `BANKS`.
- Each new `BANKS[id]` array gets **12 authored items** (matches existing bank size).
  Items must be real, correct trivia/content — no placeholder text.
- After every `index.html` change: repack, run `dc-smoke-test.js` (zero `pageerror`s
  required), then commit. Never leave `template.html` committed — it's a scratch
  working file, regenerated by `dc-unpack.js` each task and deleted after repacking
  (add it to `.gitignore` in Task 1).
- House-best persistence (`localStorage['marquee-quiz-records']`, keyed by `modeId`)
  must keep working unmodified for every mode, old and new.

- [ ] **Step 3: Write the repack script**

Create `scripts/dc-repack.js`:

```javascript
const fs = require('fs');
const srcPath = process.argv[2] || 'index.html';
const outPath = process.argv[3] || 'index.html';
const data = fs.readFileSync(srcPath, 'utf8');
const html = fs.readFileSync('template.html', 'utf8');
const re = /(<script type="__bundler\/template">)([\s\S]*?)(<\/script>)/;
const m = data.match(re);
if (!m) throw new Error('__bundler/template script not found in ' + srcPath);
// Escape every "/" so no literal "</script" sequence can appear inside the JSON
// string and prematurely close the wrapping <script> tag in the browser's HTML
// parser (this is why the original file encodes "/" as "/" — "\/" is the
// JSON-equivalent escape and is just as safe).
let encoded = JSON.stringify(html).replace(/\//g, '\\/');
const newData = data.slice(0, m.index) + m[1] + encoded + m[3] +
  data.slice(m.index + m[0].length);
fs.writeFileSync(outPath, newData, 'utf8');
console.log('wrote', outPath, 'length', newData.length, '(was', data.length, ')');
```

- [ ] **Step 4: Write the smoke-test script**

Create `scripts/dc-smoke-test.js`:

```javascript
const fs = require('fs');
const path = require('path');
const { chromium } = require('playwright-core');

function findChrome() {
  const cacheDir = path.join(process.env.HOME, '.cache/ms-playwright');
  const dirs = fs.readdirSync(cacheDir).filter(d => /^chromium-\d+$/.test(d));
  for (const d of dirs) {
    const p1 = path.join(cacheDir, d, 'chrome-linux64/chrome');
    const p2 = path.join(cacheDir, d, 'chrome-linux/chrome');
    if (fs.existsSync(p1)) return p1;
    if (fs.existsSync(p2)) return p2;
  }
  throw new Error('no chromium build found in ' + cacheDir);
}

async function main() {
  const file = process.argv[2];
  const categoryLabel = process.argv[3] || '';
  const modeLabel = process.argv[4] || '';
  if (!file) { console.error('usage: node dc-smoke-test.js <index.html> [categoryLabel] [modeLabel]'); process.exit(1); }

  const browser = await chromium.launch({ executablePath: findChrome() });
  const page = await browser.newPage();
  const errors = [];
  page.on('pageerror', e => errors.push('pageerror: ' + e.message));

  await page.goto('file://' + path.resolve(file));
  await page.waitForTimeout(1200);

  if (categoryLabel) {
    await page.getByText(categoryLabel, { exact: false }).first().click();
    await page.waitForTimeout(400);
  }
  if (modeLabel) {
    await page.getByText(modeLabel, { exact: false }).first().click();
    await page.waitForTimeout(600);
    const body1 = await page.textContent('body');
    console.log('after entering mode, contains REEL:', body1.includes('REEL'));
    const buttons = await page.locator('button').all();
    if (buttons.length) { await buttons[Math.min(3, buttons.length - 1)].click().catch(() => {}); }
    await page.waitForTimeout(500);
  }

  const finalText = await page.textContent('body');
  console.log('final body snippet:', finalText.slice(0, 200).replace(/\s+/g, ' '));
  console.log('errors:', errors);
  await browser.close();
  if (errors.length) process.exit(1);
}

main();
```
